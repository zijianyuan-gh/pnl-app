Daybook — Support

Daybook: P&L Trading Journal · a personal record-keeping and analysis tool

Daybook is a calendar journal for your own trading results: record each day's realized profit or loss, see green and red days at a glance, and review your performance by account. It does not connect to brokers, execute trades, hold money or give investment advice.

Contact

Questions, problems or feature requests: open an issue on GitHub. Please don't attach backup files — they contain your trading history.

Backups

  • Export: Accounts → Export full backup (JSON) → Save to Files (for example iCloud Drive).
  • Restore: Accounts → Restore from backup → choose the file. The file's SHA-256 checksum is verified before anything is restored. "Merge" never creates duplicates; "Replace" asks for confirmation and can be undone right away.
  • iOS app automatic copy: after every change the app saves a full backup in Files → On My iPhone → Daybook. If the app's storage is ever found empty, Daybook offers to restore it.
  • Your data does not sync between devices. Use a backup file to move it.

Moving from the web app to the iOS app

  1. In the web app (Safari or the Home Screen icon): Accounts → Export full backup (JSON) → Save to Files.
  2. Install Daybook from the App Store and open it.
  3. Accounts → Restore from backup → pick the file → Replace (or Merge).
  4. Check your balance and a few trades. Your web-app data is not deleted; you can remove it later in the web app with Accounts → Erase all data.

App Lock (Face ID / Touch ID)

Accounts → Preferences → App Lock. Daybook then asks for Face ID, Touch ID or your device passcode when it opens and hides its content in the app switcher. App Lock is a screen lock; it does not add encryption to your data.

Privacy

Daybook collects no data. See the privacy policy.

Daybook 支持

Daybook 是个人交易盈亏日历：记录每天的已实现盈亏，一眼看清盈利日与亏损日，并按账户回顾表现。它不连接券商、不执行交易、不托管资金、不提供投资建议。

联系

问题、故障或建议：在 GitHub 提交 Issue。请不要附上备份文件——其中包含你的交易记录。

备份

  • 导出：账户 → 导出完整备份（JSON）→ 存储到“文件”（如 iCloud 云盘）。
  • 恢复：账户 → 从备份恢复 → 选择文件。恢复前会校验文件的 SHA-256；「合并」不会产生重复；「替换」需要确认，并可立即撤销。
  • iOS App 自动副本：每次修改后，App 会在「文件 → 我的 iPhone → Daybook」保存完整备份。如果 App 存储被发现为空，Daybook 会提示从中恢复。
  • 数据不会在设备之间同步，请用备份文件迁移。

从网页版迁移到 iOS App

  1. 在网页版（Safari 或主屏幕图标）中：账户 → 导出完整备份（JSON）→ 存储到“文件”。
  2. 从 App Store 安装并打开 Daybook。
  3. 账户 → 从备份恢复 → 选择该文件 → 替换（或合并）。
  4. 核对余额和几笔交易。网页版中的数据不会被删除，之后可在网页版中用「账户 → 清空全部数据」自行删除。

应用锁（面容 ID / 触控 ID）

账户 → 偏好设置 → 应用锁。开启后，打开 Daybook 需要面容 ID、触控 ID 或设备密码，并在多任务界面中隐藏内容。应用锁是屏幕锁，不会对数据另行加密。

隐私

Daybook 不收集任何数据，详见 隐私政策。
