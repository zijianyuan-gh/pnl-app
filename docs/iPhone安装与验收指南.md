# Daybook iPhone 安装与验收指南

> 前提：网站已发布到 HTTPS 地址（发布后在 GitHub → Actions → “CI & deploy” 运行摘要中显示 `Live: https://…`）。以下用 `https://你的地址` 代替。

## 1. 安装到主屏幕
1. 用 **Safari** 打开 `https://你的地址`（必须是 Safari）。
2. 点底部 **分享** 按钮 → **添加到主屏幕** → 名称保持 “Daybook” → **添加**。
3. **以后只从主屏幕图标打开。** Safari 标签页和主屏幕 App 的数据互不相通。
4. 打开 账户 → 数据与备份，应显示「正在以主屏幕 App 方式运行」。「持久化存储」如显示未授予，点「申请」；iOS 不一定授予，此时更要定期备份。

## 2. 记录与离线录入
1. 点底部 `+` → 数字键盘弹出 → 输入金额 → 选「盈利 / 亏损」→ 保存。
2. 离线验收：打开 **飞行模式** → 从多任务界面关闭 Daybook → 重新打开 → 能正常打开、能看到全部记录 → 新增一笔 → 关闭飞行模式 → 记录仍在。
3. 输入一半被打断（来电、App 被关闭、更新）时，下次点 `+` 会显示「已恢复未保存的记录」。

## 3. 导出备份（建议每周一次）
1. 账户 → 数据与备份 → **导出完整备份（JSON）**。
2. 点 **分享 / 存储到“文件”** → 选择 **存储到“文件”** → **iCloud 云盘**（或“我的 iPhone”）→ 存储。
3. 在「文件」App 中确认出现 `daybook-backup-日期-时间.json`。
4. 备份未加密、含全部交易记录：不要通过邮件或聊天发送，不要上传到公开位置。Daybook 不能自动写入 iCloud 云盘，每次都需要你在分享面板中保存。

## 4. 恢复备份
1. 账户 → 数据与备份 → **从备份恢复** → 在「文件」中选择备份文件。
2. 确认显示「校验通过（SHA-256）」以及正确的账户数、交易数、净盈亏。
3. 选择：
   - **合并到当前数据**：日常补回数据，不会产生重复；
   - **替换当前全部数据**：换新手机或清空后使用（会二次确认）。
4. 恢复后可立即点「撤销」；但如果恢复后你又改过数据，撤销会被拒绝并保留现有数据（不会覆盖）。

## 5. 一次性验收清单（开始记真实交易前）
- [ ] 显示「正在以主屏幕 App 方式运行」
- [ ] 记录 `+1234.56`（标的 TEST），日历显示 `+$1.2K`，点开显示 `+$1,234.56`
- [ ] 关闭 App 再打开，金额一致
- [ ] 飞行模式下冷启动、查看、新增都正常
- [ ] 导出备份到 iCloud 云盘成功
- [ ] 从该文件恢复（合并）显示校验通过、无重复
- [ ] 发布新版本后出现「有新版本可用」，刷新后数据一致
- [ ] 删除 TEST 记录（或「清空全部数据」）后开始记录真实交易

任何一步不符合预期，请先不要记录真实交易。
